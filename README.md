One funny line of awkward small talk that one robot says to another while
they ride an elevator together.

[Competition](https://make.fun/competitions/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f)

## Run

```sh
node main.ts
```

Writes exactly one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
